## 🚀 Deployment

### 1. Deploy on Render
- Build: `npm install`
- Start: `node server.js`

### 2. Pair WhatsApp
- Check Render logs for pairing code
- WhatsApp → Linked Devices → Link with Phone Number
- Enter the code

### 3. Keep Alive
- Add UptimeRobot monitor on `/ping`
- Ping every 5 minutes
